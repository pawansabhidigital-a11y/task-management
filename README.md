# Webinar Funnel Operations Command Center

Internal operations and task management dashboard for coaching and webinar funnel workflows.

## Features
- Daily webinar and replay tracking across 7 clients
- Task priority matrix (P0 to P3)
- Monthly Silver Offer & Showcase commitment tracking
- Operational alerts and 15-minute stuck desk

## Tech Stack
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
